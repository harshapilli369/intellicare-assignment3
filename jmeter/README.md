# JMeter Load Testing

Apache JMeter test plan and results for the IntelliCare performance assessment.

## Contents

| Path | Description |
|------|-------------|
| `intellicare-test-plan.jmx` | Test plan covering both load scenarios |
| `results/baseline/` | Results before any optimizations were applied |
| `results/optimized/` | Results after the four optimizations |

Each results folder contains `light.csv`, `moderate.csv` and an HTML dashboard
generated by JMeter's `-e -o` flags.

## Scenarios

| Scenario | Threads | Ramp-up | Think time |
|----------|---------|---------|------------|
| Light    | 10      | 30 s    | 500 ms |
| Moderate | 50      | 60 s    | 500 ms |

Both scenarios exercise the same samplers: the login endpoint, the application
entry point and JS/CSS bundles, the patient directory with and without a search
term, patient detail, the appointment list, and the AI pre-appointment summary
endpoint.

## Reproducing the runs

Start the backend with the seeded database and the built frontend, then:

```bash
jmeter -n -t jmeter/intellicare-test-plan.jmx -Jusers=10 -Jrampup=30 \
  -l jmeter/results/baseline/light.csv \
  -e -o jmeter/results/baseline/light-report

jmeter -n -t jmeter/intellicare-test-plan.jmx -Jusers=50 -Jrampup=60 \
  -l jmeter/results/baseline/moderate.csv \
  -e -o jmeter/results/baseline/moderate-report
```

Swap `baseline` for `optimized` to produce the second set of results. The test
plan itself is unchanged between the two runs so the comparison stays valid.
